# HH.ru Job Market Pipeline (Airflow + ClickHouse + Metabase)

ETL-пайплайн для сбора и анализа вакансий Data Engineer с сайта hh.ru. Проект позволяет отслеживать рынок труда, фильтровать вакансии по опыту и получать красивые дайджесты на почту.

## 🏗 Архитектура пайплайна

1. **Extract (extract.py)**: Делает запросы к API hh.ru по списку синонимов (Data Engineer, ETL Developer и др.). Собирает данные о вакансиях и получает полное описание для каждой из них.
2. **Transform (transform.py)**: Очищает сырые JSON-данные, отсеивает нерелевантные вакансии (руководящие должности) и формирует удобный датафрейм.
3. **Load & Report (send_email.py)**: Формирует красивый HTML-дайджест с вакансиями (сортировка по опыту: от 1-3 лет до «Более 6 лет») и отправляет его на почту.

## 🛠 Технологический стек

* **Orchestration:** Apache Airflow (опционально, для запуска по расписанию)
* **Data Processing:** Python (Pandas, Requests)
* **Storage:** ClickHouse (для дальнейшей аналитики)
* **Reporting:** Python (smtplib), HTML/CSS для писем
* **Infrastructure:** Docker, Docker Compose

## 🚀 Ключевые инженерные решения (Highlights)

* **Безопасность токенов:** Токен от API hh.ru и пароли для почты вынесены в .env файл и не попадают в Git.
* **Умная фильтрация:** Используется поиск по списку синонимов с последующей проверкой названия вакансии (отсеиваются менеджеры и руководители).
* **Пользовательский опыт:** Вместо сухих таблиц CSV, данные выгружаются в виде красивого HTML-письма, которое удобно читать с телефона.
* **Функциональная диагностика:** Проект изначально создавался для анализа рынка (какие навыки востребованы, где больше вакансий для джунов/мидлов).

## 📦 Как запустить локально

### 1. Клонирование и настройка
Склонируйте репозиторий:

```bash
git clone <your-repo-url>
cd hh_job_pipeline
```

Создайте файл .env в корне проекта и добавьте туда ваши токены:

```env
HH_API_TOKEN=ваш_токен_от_hh_ru
EMAIL_USER=ваша_почта@mail.ru
EMAIL_PASSWORD=пароль_приложения
EMAIL_TO=ваша_почта@mail.ru
```

### 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 3. Запуск сбора данных

```bash
python src/extract.py
```

### 4. Отправка на почту

```bash
python src/send_email.py
```
